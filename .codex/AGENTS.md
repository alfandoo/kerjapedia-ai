# Browser/tool selection

- Use Playwright for repeatable UI testing, regression tests, E2E tests, screenshots for test validation, and flows that should be committed to the repo.
- Use the browser plugin/tool for exploratory browsing, inspecting pages, one-off interactions, and research.
- If both can solve the task, prefer Playwright when the result should be reproducible.
- Do not use both for the same task unless one is needed to diagnose a failure in the other.
